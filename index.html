How It Works

1. Install and Launch

Drag Monocle to Applications. Open and grant accessibility permissions once.

2. Activate Focus

Hit your custom hotkey (default: Option + Space). Active window sharpens; rest blurs instantly.

3. Switch and Customize

Move between apps—blur adapts automatically. Tweak intensity in the menu bar anytime.

4. Deactivate Seamlessly

Same hotkey toggles off. Or set to auto-pause during presentations and screenshares.

FAQ

Does it work on macOS Sequoia?

Yes, fully optimized for macOS 14 and later, including Sonoma and Sequoia.

Is there a performance impact?

Negligible. Uses hardware acceleration for buttery-smooth rendering on M1+ chips.

Can I exclude certain apps?

Yes, add exclusions in Settings for full-screen apps or trusted windows.

What hotkeys are available?

Fully customizable. Default: Option + Space to toggle, Option + Shift + Space for settings.
